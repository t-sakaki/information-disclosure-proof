# Disclosure Proof — 実演入りデモ動画 台本

ETHGlobalルール: 2〜4分、720p以上、TTS/AI音声禁止（肉声のみ）、音声加速編集不可。
構成: スライド(導入・締め) + ブラウザでの実演(核心部分)
合計目安: 約3分20秒

## Part A: 導入（スライド, 約35秒）

**[cover スライド]**（約15秒）
> こんにちは。これは Disclosure Proof、行政文書開示請求を、オンチェーンの証明と市民の投げ銭でつなぐプロジェクトです。ETHGlobal Tokyo 2026、Base Sepolia上で構築しました。

**[problem スライド]**（約20秒）
> 日本には公的なオンブズマン制度がありません。開示請求をしても、その記録は本人の手元にしか残らず、後から誰も検証できません。そして、そうした地道な活動を応援する手段もありませんでした。

## Part B: 実演（ブラウザ, 約2分）

画面を `http://localhost:8000/`（または本番デプロイURL）に切り替える。

### B-1. ウォレット接続（約10秒）
- 【操作】「ウォレットを接続」をクリック → MetaMaskで承認 → Base Sepoliaに自動切り替え
> まず、自分のウォレットを接続します。この後の操作はすべて、私自身の鍵で署名します。サーバーが代理で署名することはありません。

### B-2. 開示請求を刻印（約35秒）
- 【操作】ファイルを選択（サンプルのPDF等）
- 【操作】請求先に「〇〇市長」、請求の種類はそのまま、要約に具体例を入力
- 【操作】「刻印する」→ MetaMaskの署名ポップアップ→承認 → 完了表示
> 実際に開示請求を刻印してみます。対象の文書を選び、請求先と要約を入力します。「刻印する」を押すと、ウォレットで署名を求められます。承認すると、このハッシュと内容がBase Sepolia上に記録されます。
- 【操作】完了後、表示された attestation UID を指す（画面上で強調）
> このattestation UIDが発行されました。これが、これから応援する対象になります。

### B-3. 投げ銭で応援（約35秒）
- 【操作】投げ銭フォームに、先ほどのUIDを入力（自動入力されていればそのまま）
- 【操作】通貨をUSDCに切り替え、金額を入力
- 【操作】「投げ銭する」→ 送金の署名→承認 → 応援記録の署名→承認 → 完了表示
> 次に、この請求を投げ銭で応援します。通貨はETHまたはUSDCから選べます。今回はUSDCで応援してみます。送金と、応援の記録、2回署名するとオンチェーンに残ります。

### B-4. リーダーボード・急上昇（約20秒）
- 【操作】「最新の状態を取得」をクリック → リーダーボードに反映されているのを見せる
- 【操作】急上昇セクションもスクロールして見せる
> リーダーボードと急上昇ランキングは、EASのデータから直接集計しているので、別のデータベースは必要ありません。投げ銭した直後に、この通りすぐ反映されます。

### B-5. シェアボタン（約10秒）
- 【操作】投げ銭完了メッセージ内の「SNSでシェア」ボタンを指す
> 投げ銭が終わると、ワンタップでSNSにシェアできます。このリンク経由の応援は紹介として記録され、応援が次の応援を呼ぶ仕組みになっています。

## 収録前チェックリスト

- [ ] `uvicorn app:app --reload` でローカルサーバーを起動（または本番デプロイURLを使う）
- [ ] MetaMaskに `CivicLens-Notary`（または別の実演用アドレス）が入っており、Base Sepolia ETH と USDC の残高が十分にある
- [ ] サンプルの開示請求書ファイル（PDF等、ダミーで可）を手元に用意
- [ ] ブラウザのズーム・ウィンドウサイズを録画に適した大きさに調整（720p以上で録画されるように）
- [ ] MetaMaskの通知が録画の邪魔にならない位置に配置
- [ ] 静かな環境・エコーのない場所で収録
- [ ] 話す速度はそのまま収録する（後から音声を加速する編集は禁止）
- [ ] 一度通しでリハーサルし、実演部分が2分前後に収まるか確認する

## 補足

- 実演中にトランザクションの確定待ちで数秒〜十数秒の間が空く場合があります。台本の分量はその待ち時間も込みで見積もっていますが、実際のネットワーク状況次第で前後する可能性があるため、リハーサルで尺を必ず確認してください
- attestation UIDやトランザクションハッシュが画面に表示された際、可能であれば軽くカーソルや矢印で指し示すと分かりやすくなります
