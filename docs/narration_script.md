# Disclosure Proof — デモ動画 読み上げ原稿

合計目安: 約3分5秒（実演部分を挟む場合はスライド部分をさらに短縮）

## 1. カバー（約15秒）

こんにちは。これは Disclosure Proof、行政文書開示請求を、オンチェーンの証明と市民の投げ銭でつなぐプロジェクトです。ETHGlobal Tokyo 2026、Base Sepolia上で構築しました。

## 2. 課題（約20秒）

日本には公的なオンブズマン制度がありません。開示請求をしても、その記録は本人の手元にしか残らず、後から誰も検証できません。そして、そうした地道な活動を応援する手段もありませんでした。

## 3. ソリューション（約20秒）

私たちは3つの柱で解決します。証明、応援、拡散です。開示請求をEASでオンチェーンに刻印し、ETHやUSDCで投げ銭として応援でき、その応援がさらに次の応援を呼ぶ仕組みを作りました。

## 4. システム構成（約20秒）

仕組みはシンプルです。市民は自分のウォレットで直接署名し、Base Sepolia上のEASコントラクトにattestationを送信します。サーバーは秘密鍵を持たず、代理署名は一切行いません。

## 5. フロー①開示請求の刻印（約25秒）

刻印はこの5ステップです。文書のハッシュを計算し、請求先や請求種別を入力し、ウォレットで署名する。Base Sepoliaで確定すると、attestation UIDが発行され、これが投げ銭の対象になります。

## 6. フロー②投げ銭（約25秒）

投げ銭も同様です。応援したい請求を選び、ETHかUSDC、金額を指定して署名する。送金と同時に応援メッセージがオンチェーンに記録され、リーダーボードに即座に反映されます。

## 7. 拡散ループ（約20秒）

投げ銭した直後に、ワンタップでSNSにシェアできます。このリンクには紹介者のアドレスが埋め込まれていて、新しい応援者を呼び込みます。急上昇ランキングが、この勢いを可視化します。

## 8. 技術スタック（約15秒）

技術スタックは、Base Sepolia、EAS、ethers.js、ENS、そしてUSDC。すべてハッカソン期間中にゼロから実装しました。

## 9. 今後の展望（約15秒）

今後はフォロー機能の実装、メインネットへの移行、そして実際の市民活動との連携を目指します。
